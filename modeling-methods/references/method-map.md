# 按结构找方法

用途：为深入研究提供常见方法的基础参照和检索词，只读与当前任务有关的行。此表不限定探索范围，也不能作为最终设计成果。选定前查清公式、成立条件和实现参数，结合本题推导与比较；不要因为某方法出现在表中就采用或运行它。

| 当前对象 | 先看什么 | 可考虑的入口 | 会影响选择的证据 |
|---|---|---|---|
| 解释变量关系 | 变量类型、线性/单调、个体或时间依赖、混杂 | 描述统计、相关分析、回归、分组或混合效应 | 散点/分组结构、残差、条件变化；相关不自动支持干预 |
| 预测连续量 | 使用时已知什么、样本量、非线性、外推范围 | 线性模型、样条、树模型；有充分数据和理由再用复杂模型 | 按实际应用对象划分的误差；训练拟合不代表泛化 |
| 时间预测 | 预测跨度、趋势季节性、频率、历史长度 | 简单持续/季节参照、时间序列模型、带时间特征的回归 | 时间顺序回测、残差结构；不要随机拆散时间制造乐观误差 |
| 分类 | 标签来源、类别比例、误判代价、个体重复 | 逻辑回归、树模型、SVM等 | 与目标匹配的验证、阈值影响、小类失败；非所有任务都以准确率选型 |
| 无标签分组 | 为什么分组、距离/尺度、组形状 | K-means、层次聚类或基于机制分组 | 稳定性、可解释性、对后续决策的帮助；得到分组不等于得到行动方案 |
| 综合评价 | 指标含义和方向、冗余、偏好来源 | AHP、熵权、TOPSIS或直接效用模型 | 权重与排序的关系；数据差异不等于实际重要性 |
| 方案优化 | 变量是否连续/整数，目标约束能否利用线性、凸性、网络或阶段结构 | 枚举、线性/整数规划、动态规划、非线性优化 | 可行性、规模、界限/求解状态；先利用结构，再决定是否需要通用随机搜索 |
| 昂贵或复杂搜索 | 维数、可行域、噪声、单点评价耗时、反馈是否稀疏 | 启发式、多初值、代理辅助或贝叶斯优化等 | 在实际预算下得到的真实目标和失败情形；昂贵不必然适合某种算法 |
| 动态机理 | 状态量、守恒、空间变化、初边值、时间尺度 | 代数关系、差分、ODE、PDE或机制与数据结合 | 与已知关系和极限条件相符、离散误差、参数可辨识性 |
| 不确定性传播 | 哪些输入随机、分布来源、相关性 | 解析传播、情景、蒙特卡洛 | 输出分布随采样与假设的变化；不能自行指定方便的分布当事实 |
| 网络和路径 | 节点/边与现实对象的对应、方向、权重、容量 | 图算法、流、路径与组合优化 | 真实约束满足、规模和可计算性 |

## 先写数学关系，再选求解器

优化的一个通用表达是 `min f(x; θ)`，受 `g(x; θ) ≤ 0`、`h(x; θ) = 0` 和变量域限制。`x` 是要决定的量，`θ` 是已知或待估参数。对具体题目，必须说明每个量实际代表什么、单位是什么、取值范围如何得到。

相同现实问题可以有不同表示：逐个对象独立参数、共享参数、按阶段的状态转移、消去满足几何关系的变量。先解释表示改变了什么；求解器在既定表示上搜索，不能替代这一步。

## 数据分析接到决策时

例如“按人群分组后推荐行动时点”：分组只给出了对象集合；还需估计每组在不同时点的表现，并依据损失与允许时段选择行动。损失权重没有依据时，把它保留为情景或待裁决参数，不能反向调权重来产生预想答案。

重复测量可考虑显式描述个体差异，时间预测须考虑时间结构。采用哪个具体模型仍要看响应量范围、样本与机制。培训总结的混合效应、生存分析等是结构案例，不是新题默认组合。

## 选择的最短说明

围绕实际决定写：采用的方法如何连接输入输出；关键前提是什么；哪个推导、试算或数据现象支持它；另一个候选为什么暂不采用。已存在合适实现时复用并核对，不为了形成“多模型比较”重复写代码。

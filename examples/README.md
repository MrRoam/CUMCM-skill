# 离线协作小练习

`supply-plan`是6个点、12个需求组的纯合成（synthetic）补给案例，没有真实灾情或个人数据。题面含手算基线，参考程序能在很短时间内穷举核对。这里不附隐藏标准答案。

有Python 3.8+与Git即可，在Skills仓库根运行：

```text
python examples/offline_drill.py --out ../my-team-drill
```

必须指定尚不存在的目录，父目录须已存在；脚本不会覆盖旧练习。它只在该目录建立一个种子仓库和三个本地克隆，用两个Git bundle交换工作，全程离线，临时提交身份为`Synthetic Team Drill`，不读账号、不改全局Git配置。

这模拟了模型负责人更新条件、求解负责人交付候选、整合者接收结果。脚本会验证：Git合并可以成功，但旧结果的凭据仍会被拒绝。**三个克隆不是三个真实账号，也不是三个学生已理解模型的证据。**

生成后，让一个没有看过搭建过程的新Codex，以输出目录中的`integrator`为工作区接手，可直接发：

> 请阅读当前题目、团队决定和已有结果，检查交付能否采用。必要时复算修正，保存能由队友核对的结果，并写一段带单位和适用边界的解释。除已安装的团队Skill工具外，不阅读工作区上级目录、搭建脚本或其他克隆。不要把重新封存旧文件当成重新计算。

检查接手者是否找到了条件变化、是否实际重跑、说明与结果是否一致。最后由学生用手算基线解释重叠为什么只计一次，并复述最终目标与约束。记录这些实际表现；不能仅凭脚本通过就声称三人协作或学习效果已经验证。
